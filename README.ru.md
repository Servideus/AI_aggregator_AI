# AI news digest for Telegram

Python-скрипт собирает сообщения из выбранных публичных Telegram-каналов, передаёт их Gemini и сохраняет русскоязычный дайджест максимум из десяти новостей об ИИ. Готовый текст можно отправить в настроенный чат или канал. Вчерашний локальный дайджест используется для исключения повторов.

## Установка

Нужны Python 3.11 или новее, собственные Telegram API ID/hash и ключ Gemini API.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните `TG_API_ID`, `TG_API_HASH` и `GEMINI_API_KEY`. Telegram API ID/hash доступны на [my.telegram.org](https://my.telegram.org), ключ Gemini — в [Google AI Studio](https://aistudio.google.com).

Замените пример в `sources.yml` именами публичных каналов без `@`. Используются поля `username`, `title` и `enabled`. Приоритетов источников и хранения в SQLite в этой версии нет.

## Настройка

`DIGEST_PEER` можно оставить пустым: результат будет только в файле и консоли. Для отправки укажите свой чат или канал; Telegram-аккаунт должен иметь право писать туда. `UTC_OFFSET_HOURS` задаёт смещение часового пояса для даты дайджеста. Имена моделей задаются в `.env.example`; их доступность зависит от аккаунта API.

## Запуск

```powershell
./start_bot.bat
```

При первом запуске потребуется войти в Telegram и, если включена двухфакторная защита, ввести пароль. Используется пользовательская Telegram-сессия, а не токен бота из BotFather. Файл `.session` даёт доступ к аккаунту: храните его приватно.

Один запуск создаёт один дайджест. Автоматическое расписание настраивается отдельно. Сообщения и вчерашний дайджест отправляются Gemini; запросы могут быть платными. Перед включением автоматической отправки проверьте локальный результат.

## Ограничения

Сохранены фильтры российских брендов и постов с большим числом ссылок. Они могут исключать полезные новости. Длинный дайджест может превысить лимит Telegram: автоматического деления сообщения нет. Проверка фактов и точности новостей остаётся задачей пользователя.

## Проверки

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Локальные тесты проверяют загрузку источников, настройки JSON в SDK, генерацию с подменённой моделью, сохранение перед отправкой и отсутствие подключения при пустом адресате. Вход в настоящий Telegram и доступность моделей Gemini этими тестами не проверяются. Справка по SDK: [Google Gen AI](https://googleapis.github.io/python-genai/).

## Данные и лицензия

Публичная версия содержит код и общие примеры настроек. Ключи, сессии аккаунта, личная подборка каналов, готовые дайджесты, базы, локальные пути и служебные файлы исключены. История исходной рабочей папки не переносилась.
